# Users URLs

This file maps URL patterns to view functions for the users application, handling authentication.

## URL Patterns

- `"register/"` (name: `register`): Maps to `views.register` - Handles user registration.
- `"login/"` (name: `login`): Maps to `views.login_view` - Handles user login.
- `"logout/"` (name: `logout`): Maps to `views.logout_view` - Handles user logout.
